# Big Brain Ape Dashboard

Clean, professional dark-themed stock analysis dashboard for the Big Brain Ape trading bot.

## Features
- Live price display
- Strong Buy / Buy recommendation card
- Analyst ratings breakdown (Strong Buy / Buy / Hold / Sell)
- Key metrics (Market Cap, 50-day & 200-day averages, 52-week range, Beta)
- Full live TradingView chart (dark theme)

## Live Site
Once GitHub Pages is enabled:
**https://simzy420.github.io/big-brain-ape-dashboard/**

### How to turn on the website (one-time):
1. Go to https://github.com/Simzy420/big-brain-ape-dashboard
2. Click **Settings**
3. Click **Pages** on the left
4. Under "Source" choose **Deploy from a branch**
5. Select branch **main** and folder **/ (root)**
6. Click Save

Wait 1–2 minutes and the link above will work.
